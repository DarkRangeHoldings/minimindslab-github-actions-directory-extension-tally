# File Extension Counts

Summarize repository file extensions from a supplied path list to help review project composition in CI.

Generated by MiniMindsLab 02.13 GitHub Action Factory.

## Usage

```yaml
- uses: ./path-to-action
  id: miniminds
  with:
    payload: '{"paths":["src/a.js","src/b.js","README.md","LICENSE"]}'
- run: echo '${{ steps.miniminds.outputs.result }}'
```

Runtime: Node 24. No external dependencies. No network access.
